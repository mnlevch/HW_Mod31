# Анализ CSV-файлов
## Описание
Приложение с использованием Streamlit для анализа данных CSV-файлов.
Основной функционал:
- возможность просмотра содержимого файла;
- возможность выбора отображаемых столбцов;
- статистический анализ (количество, среднее, медиана, среднеквадратичное отклонение);
- визуализация данных (линейный график, диаграмма рассеяния, столбчатая диаграмма).
### Установка необходимых библиотек для корректной работы приложения
```bash
pip install streamlit pandas numpy altair
```
### Открыть приложение
```bash
streamlit run main.py
```
